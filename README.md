# LostFront Launcher

Официальный лаунчер военного Minecraft-проекта **LostFront** (Minecraft 1.20.1 + Forge).

## Файлы CDN

| Файл | Назначение | Кто редактирует |
|---|---|---|
| `version.json` | Обновления лаунчера (версия, ссылка на zip, SHA-256, флаг `mandatory`) | после каждой сборки |
| `news.json` | Новости в лаунчере — правится прямо на GitHub через Edit | владелец, в любой момент |
| `manifest-mods.json` | Хеши и ссылки на моды для синхронизации сборки | при обновлении модов |

Сами моды лежат в [Releases](../../releases) (`mods-v1`).

## Публикация новости

1. Откройте `news.json` на GitHub, нажмите ✏ Edit.
2. Добавьте объект в массив `news` (поля: id, title, date, category, summary, content, author).
3. Commit — новость появится у всех игроков при следующем запуске лаунчера (не дольше часа).
